# 🎵 New York - Ed Sheeran

Projeto de estudo de **HTML** desenvolvido para praticar a hierarquia de tags de texto, inserção de mídias e criação de hiperlinks entre páginas.

O site apresenta uma música, fala sobre o cantor e exibe imagens que a representam.

---

## 📄 Sobre o projeto

O site é composto por **três páginas** conectadas por links:

- **`index.html`** — Tela principal (ponto de entrada do site), com o título da música, o artista, a capa do álbum e um texto de apresentação.
- **`detalhes.html`** — Tela com informações detalhadas sobre a música e o artista, além dos recursos visuais.
- **`sobre.html`** — Tela com os dados do aluno (foto, nome, curso, período, GitHub e LinkedIn) e um botão para voltar à tela principal.

---

## 🏷️ Tags utilizadas

| Tag | O que faz |
|------|-----------|
| `<h1>` a `<h6>` | Criam títulos e subtítulos organizados por hierarquia |
| `<p>` | Define um parágrafo de texto |
| `<strong>` | Destaca um trecho como importante (negrito) |
| `<em>` | Aplica ênfase semântica ao texto (itálico) |
| `<mark>` | Aplica um fundo destacado/amarelo sobre o texto |
| `<small>` | Reduz o tamanho do texto (avisos e termos) |
| `<sub>` / `<sup>` | Formata subscrito e sobrescrito |
| `<br>` | Insere uma quebra de linha manual |
| `<hr>` | Cria uma linha horizontal para separar temas |
| `<img>` | Insere imagens (todas com descrição no atributo `alt`) |
| `<a>` | Cria hiperlinks entre as páginas e para sites externos |
| `<button>` | Botões de navegação |

---

## 📁 Organização dos arquivos

```
projeto/
│
├── index.html
├── detalhes.html
├── sobre.html
│
└── imagens/
    ├── capa.jpg
    └── ...
```

As imagens ficam na pasta **`imagens`**, em formato `.jpg` ou `.png`.

---

## ♿ Acessibilidade

Todas as imagens possuem uma descrição detalhada no atributo `alt`, garantindo que o conteúdo seja compreensível para pessoas que utilizam leitores de tela.
